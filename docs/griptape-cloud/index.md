# Griptape Cloud

[Griptape Cloud](https://cloud.griptape.ai/) provides managed services for your AI app stack that you can use from the Griptape Framework.

## Store Your Files

Store files in [Data Lakes](data-lakes/data-lakes.md) and access them from your code with the Griptape Framework.

## APIs

All of our features can be called via API with a [Griptape Cloud API Key](https://cloud.griptape.ai/configuration/api-keys). See the [API Reference](api/api-reference.md) for detailed information.
